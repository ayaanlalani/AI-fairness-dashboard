# Cross-Dataset LLM Benchmark Comparison

This artifact release treats OpenAI as the primary LLM benchmark.

Primary report:

- `artifacts/consolidated/llm_benchmark_comparison_openai.md`
- `artifacts/consolidated/deterministic_vs_openai_short_report.md`

Legacy secondary comparison:

- `artifacts/consolidated/llm_benchmark_comparison_gemini.md`

Important interpretation note: the OpenAI benchmark receives deterministic Python-computed metric context and is evaluated on qualitative audit quality, severity alignment, statistical caution, and mitigation specificity. It is not presented as independently recomputing fairness metrics. Older Gemini artifacts are retained for provenance and for comparison against the earlier workflow.
